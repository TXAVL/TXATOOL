## Platform

(Schema value only. TXATOOL - WIN is a Windows 10/11 desktop app built with WPF/.NET, not a web app.)

## Users

Primary: IT technicians and PC repair staff who set up, optimize and clean machines for customers, on site or in a shop. Secondary: everyday PC users who tune their own machine, with little technical background.

## Product Purpose

TXATOOL - WIN ("A Software for IT Support", by TXA) is an all-in-one Windows toolkit. It covers Windows tweaks and optimization, system cleanup, hardware and Windows info, curated downloads (apps, Windows ISOs, Office, WinPE, resources), license backup, and network tools. Success means a technician finishes a machine setup or tune-up in one tool instead of many.

## Positioning

All-in-one toolkit with a Vietnamese-first experience (VN/EN localization), unlike similar tools such as winutil or optimizer, which are English-centric and single-purpose.

## Operating Context

Runs locally on Windows 10/11, installed via Inno Setup (with and without bundled .NET). Content is driven by JSON files (`Assets/Config/tweaks.json`, `preset.json`, `Download/*.json`, `Changelog/*.json`, `update_*.json`).

## Capabilities and Constraints

- Tweaks and presets, startup management, cleaning, UWP app removal.
- System, disk and hardware information.
- Download catalog with hundreds of app icons.
- License backup and MAS trace removal.
- Localization in Vietnamese and English.
- Windows desktop only. Offline/admin-rights/architecture constraints not yet confirmed.

## Product Principles

- One tool replaces many: breadth within a single coherent interface.
- Vietnamese is a first-class language, not a translation afterthought.
- Serve both the expert's speed and the novice's safety around system-changing actions.
- Content stays data-driven (JSON) so catalogs update without code changes.
