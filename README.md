# TXATOOL - WIN

An all-in-one Windows toolkit for IT support: system tweaks and optimization, cleanup, hardware info, downloads (apps, ISOs, Office, WinPE), license backup and network tools. Light and dark themes (follows Windows), Vietnamese and English.

* **Version:** 1.0.0
* **Author:** [TXAVL](https://github.com/TXAVL)
* **Based on:** HyperLis by Zit's Tech Lab. The upstream project ships no license file; this fork keeps the attribution.

## Build

Requires the .NET 9 SDK on Windows.

```
dotnet build TXATOOL.csproj
```

Installer scripts: `compile_setup.bat` (bundled .NET) and `compile_setup_NoDotNet.bat` (Inno Setup 6).
